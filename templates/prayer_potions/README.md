# Prayer potion templates

Save the four cropped potion images here as `1.png`, `2.png`, `3.png`, and
`4.png`. Crop each image tightly around the potion, at the exact scale shown in
the game. The monitor tests all PNG files and clicks whichever has the best
match inside the configured inventory region.

The example config is calibrated for the current RuneLite window position and
uses template scale `0.5`. Keep the inventory tab visible while monitoring.
